## 📌 About

**Personal Finance Tracker** is a Python application designed to help users record, organize and analyze their income and expenses.

It focuses on making personal financial data easier to understand through structured records, calculations and visual analysis.

---

## ✨ Features

* 💰 Track income and expenses
* 📝 Record financial transactions
* 📊 Analyze financial data
* 📈 Generate visual insights
* 💾 Maintain finance records
* 🧮 Calculate totals and savings
* 📋 Generate financial reports

---

## 🚀 Getting Started

### 1. Clone

```bash
git clone https://github.com/PrathameshHon/PERSONAL-FINANCE-TRACKER.git
cd PERSONAL-FINANCE-TRACKER
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run

```bash
python Finance_Tracker.py
```
